## Context

ADR 0009 put every shortcut in one aggregate, but left three things that the
duplicate-and-paste feature ran into:

- The groups (`tool`, `export` and so on) and the focus contexts were fixed
  lists inside `SketchWeb.Shortcuts.Aggregate`. A feature either reused a group
  that was not its own (the clipboard chords went into `canvas`) or edited
  enforcement code, which needs approval.
- A chord that did not declare Alt did not match while Alt was held, so Esc
  could not cancel an Alt+drag. Nothing in the model said whether a chord cares
  about a modifier.
- The A23 text in `architecture/rules.exs` and ARCHITECTURE.md listed the
  registries by name. Adding `SketchWeb.ClipboardActions` left both stale, and
  nothing compared them with `@registries`.

The server's conflict model and the client matcher were also two
implementations of one relation with no check that they agree. Checking them
against each other showed the server treated the physical `Space` code as the
word "space", not the key " ", and missed that Shift+`Digit1` types `!`.

## Decision

1. **Registries declare their groups and contexts as data.** A registry may
   export `shortcut_groups/0` (the groups it owns) and `shortcut_contexts/0`
   (`%{id, description, overlaps}`). The aggregate collects them, rejects a
   group or context declared twice, an entry whose group its own registry does
   not declare, a context no registry declares and an overlap naming an unknown
   context. `SketchWeb.FixedShortcuts` declares `canvas` and `editor`, which do
   not overlap. The clipboard chords move to a `clipboard` group.
2. **Conflicts are checked across contexts that can be active at once.** Two
   chords collide when their contexts are equal or one declares the other in
   `overlaps` (symmetric). A canvas-only context that overlaps `canvas` cannot
   reuse a `canvas` chord; one that never overlaps can.
3. **Every chord declares a modifier policy.** `modifiers: :exact` requires the
   declared `mod`, `shift` and `alt`; `:ignore_alt` matches either Alt state;
   `:any` matches whatever is held. A policy that contradicts its fields fails
   to compile. Both Esc chords are `:any`, so Esc cancels a gesture started
   with Alt or Shift held. A chord that ignores a modifier collides with a chord
   that requires it.
4. **The conflict model compares the characters a press can produce.** A
   physical key produces its US character, or its unshifted character with Shift
   held; `Space`, `Minus` and the other punctuation codes map to their
   characters.
5. **A fixture keeps the server and the client in step.**
   `mix sketch.gen.render_fixtures` writes the server's verdict for every pair
   of a fixed set of chords (keys, codes and every valid combination of
   modifiers and policy). `assets/test/shortcut_parity.test.ts` requires the
   client matcher to match some modelled press with both chords exactly when the
   server says they collide, exhaustively and as a fast-check property.
6. **Docs name the registry, not its members.** A source-policy test rejects a
   line in the living docs that lists shortcut registries, element kinds,
   tools, style tokens, contexts or groups (CI requirement 10).

## Alternatives considered

- **Open groups: accept any atom.** No enforcement change per feature, but a
  typo creates a group silently and two features can share one. Rejected:
  declared ownership costs one function per registry.
- **Make the Esc chord `alt: :any` like `shift: :any`.** Smaller, but only for
  Alt, and Ctrl+Esc or Cmd+Esc during a gesture would still not cancel. The
  policy also makes the intent ("this is a cancel") explicit. Rejected.
- **Generate the registry list into ARCHITECTURE.md.** Keeps the list, but
  adds a generated region to a hand-written doc for information
  `SketchWeb.Shortcuts.registries/0` already gives. Rejected in favour of
  referring to the function and rejecting enumerations.
- **Check client and server agreement with a property test on one side only.**
  Each side would only check itself. Rejected: the fixture is generated by the
  server and checked by the client, like the render parity fixtures.

## Consequences

- A feature adds a group or context without touching
  `SketchWeb.Shortcuts.Aggregate`, and a context that can be active with
  another is checked against it at compile time.
- Every chord literal carries `modifiers:`; most are `:exact`.
- Esc, Ctrl+Esc and Alt+Esc all cancel; no chord may use Esc with a modifier in
  the contexts the Esc chords cover.
- The conflict check is stricter: Shift+`Digit1` now collides with a `!` key
  chord, and the `Space` code with the space key. The current table had no such
  pair.
- The client matcher takes one context or a list of active contexts; a context
  that overlaps another must be passed together with it while both are active.
- Re-evaluate if a layout other than US needs its own character table.
